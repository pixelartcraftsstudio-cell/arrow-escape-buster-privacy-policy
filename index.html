Arrow Escape Buster

Privacy policy for the Arrow Escape Buster game.

This repository contains the privacy policy page and a copy-ready privacy policy document for Google Play Console.

Files

  • PRIVACY_POLICY.md — copy-ready policy text
  • index.html — browser-ready privacy policy page
  • README.md — repository description

Use

You can paste the content from PRIVACY_POLICY.md directly into the Google Play Console privacy policy field.

For a public webpage, open the repository page or enable GitHub Pages from the repo settings.
